| Archivo | Ejercicio |
|---|---|
| `remo.gif` | Remo en silla / de pie |
| `pullapart.gif` | Pull-aparts |
| `pmr.gif` | Peso muerto rumano ancho |
| `puente.gif` | Puente de glúteos |
| `deadbug.gif` | Dead Bug con pies apoyados |
| `pedaleador.gif` | Posición en el pedaleador |
| `lumbar.gif` | Elongación espalda baja |
| `cuadriceps.gif` | Elongación cuádriceps |
| `pecho.gif` | Elongación pecho y hombros |

Usá solo GIFs propios (por ejemplo, grabate un clip de 3 a 5 segundos) o con licencia que permita reutilizarlos.
Si en la app fijaste un video desde la pestaña Ejercicios, ese video tiene prioridad sobre el GIF.
